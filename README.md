# Café Sales: Data Cleaning and Exploratory Analysis

Work in progress. I'm cleaning a year of messy point-of-sale data from a café (10,000 transactions, 2023) and then exploring it to see what it says about the business.

- `data/raw/` original data from Kaggle ([Cafe Sales - Dirty Data for Cleaning Training](https://www.kaggle.com/datasets/ahmedmohamed2003/cafe-sales-dirty-data-for-cleaning-training))
- `src/cleaning.py` cleaning functions
